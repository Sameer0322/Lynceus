1. Overview & Conventions

All endpoints are prefixed with /api. Request and response bodies use JSON. The Content-Type header must be application/json for all requests with a body.

Authentication

Protected endpoints require a JWT token in the Authorization header:

Authorization: Bearer <token>

Tokens are obtained from POST /api/auth/login and expire after 1 hour. Use POST /api/auth/refresh to extend the session.

Access Levels

BadgeMeaning
PublicNo authentication required
AuthenticatedAny valid JWT (viewer or admin role)
Admin onlyJWT with role=admin required

Common Response Shape

Success responses return the created/updated resource or a simple acknowledgement:

{ "ok": true }

Error responses always include an error field:

{ "error": "Descriptive error message" }

2. Authentication

User accounts are managed by an admin. Self-registration is not permitted.

POST /api/auth/login Public

Authenticate with username and password. Returns a signed JWT token.

Request Body
FieldTypeRequiredDescription
usernamestringRequiredAccount username
passwordstringRequiredAccount password (min 6 characters)
Example Request
POST /api/auth/login
Content-Type: application/json

{
  "username": "alice",
  "password": "mypassword"
}
Response — 200 OK
{
  "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJzYW1lZXIiLCJyb2xlIjoidmlld2VyIiwiaWF0IjoxNzQ4NTkwMDAwLCJleHAiOjE3NDg1OTM2MDB9.xxx",
  "expiresIn": 3600
}
Save the token value — pass it as Authorization: Bearer <token> in all subsequent requests.
Error Responses
StatusConditionBody
401Wrong username or password{ "error": "Invalid credentials" }

POST /api/auth/refresh Authenticated

Exchange a valid (non-expired) token for a new one with a fresh 1-hour expiry. No request body needed.

Example Request
POST /api/auth/refresh
Authorization: Bearer <token>
Response — 200 OK
{

5. GitHub Proxy

All endpoints proxy to https://your-ghe-host/api/v3 using the server-side PAT. The frontend never calls GHE directly. Responses are cached server-side for 3 minutes. If the primary token hits a rate limit and a secondary token is configured, the backend retries automatically.

All GitHub proxy endpoints are Public — no JWT required. If the server-side PAT is missing, all endpoints return 503 {"error":"GITHUB_TOKEN not configured on this server"}.

8. Auth Flow & Usage Guide

First-time Setup (Admin)

On first deployment, a default admin account is created automatically:

username: admin
password: Admin@123
Change the admin password immediately after first deployment using POST /api/auth/change-password.

Typical Session Flow

1.  POST /api/auth/login                        → receive token (valid 1 hour)
2.  GET  /api/teams                             → load team/repo config for sidebar
3.  GET  /api/releases                          → load existing release groups
4.  POST /api/releases                          → create a new release group (e.g. "2610")
5.  POST /api/releases/{id}/pipelines           → add a pipeline run to the group
6.  DELETE /api/releases/{id}/pipelines/{pId}   → remove a pipeline from the group
7.  POST /api/auth/refresh                      → extend session before token expires
8.  POST /api/auth/change-password              → user updates their password

Admin Workflow — Adding a New Team Member

1.  POST /api/auth/login          (admin credentials) → admin token
2.  POST /api/auth/register       { username, password } → creates viewer account
3.  Share temp password with user
4.  User logs in and calls POST /api/auth/change-password

Admin Workflow — Managing Teams

1.  POST /api/auth/login          → admin token
2.  POST /api/teams               → create team with initial repos
3.  POST /api/teams/{id}/repos    → add individual repo
4.  DELETE /api/teams/{id}/repos  → remove individual repo
5.  PUT  /api/teams/{id}          → rename team or replace full repo list
6.  DELETE /api/teams/{id}        → remove team entirely

Token Format (JWT Payload)

{
  "sub":  "alice",       // username
  "role": "viewer",       // "viewer" | "admin"
  "iat":  1748590000,     // issued at (Unix timestamp)
  "exp":  1748593600      // expires at (iat + 3600)
}
